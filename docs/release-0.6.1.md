# 0.6.1 任务岛体验修复

日期：2026-11-05

在 0.6.0 基础上按反馈修的一批交互问题。

## 修复

- **点击穿透**：命中判定完全由主进程按系统光标坐标计算（50ms），光标进胶囊才接收鼠标、离开立即穿透；
  面板移开后 320ms 自动收起，点击其它窗口即关闭。
- **打开轻单抢不到前台**：`showMain()` 增加 `app.focus({ steal: true })`，避免后台进程被前台锁拒绝。
- **全部完成不再消失**：统计把「今天已完成」补回总数，全部完成时保留岛，显示鼓励语。
- **收起胶囊变小**：140×30（原 180×36），peek 340×58。
- **动画更跟手**：形变从 560ms 降到 300ms，去掉 `will-change`（它会让 Chromium 缩放栅格、文字发虚）。
- **顶部图标对齐**：「打开轻单」改为 `SquareArrowOutUpRight` 12px，flex 居中。
- **重复鼓励语**：header 只显示「今天全部完成」，鼓励语只在面板正文出现一次。

## 新增

- **设置 → 任务岛**：开关（默认开）、进度颜色 6 选 1、提醒色说明。
- **快捷添加**：面板右上 `+` 展开输入框，支持「明天下午3点 写周报」自然语言，回车/点添加即入库；
  输入时临时让窗口可聚焦，收起后恢复不抢焦点。
- **主题跟随应用**：深浅色自动切换；进度色可配；临近到期（60 分钟内）转橙、逾期转红、完成转绿。

## 验证

- `pnpm typecheck` / `pnpm build`：通过
- 真机流程：rest → hover peek → 点击 panel → 快速添加（4/5 → 5/5）→ 移开 320ms 收起 → 回到 rest
- 命中实测：离开胶囊 `WS_EX_TRANSPARENT` 存在；进入后移除
- 打包版 0.6.1 启动正常，岛在顶部渲染
