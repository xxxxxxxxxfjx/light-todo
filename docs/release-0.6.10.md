# 0.6.10 灵动岛瘦身 · 日历切日修复 · 每日日报

日期：2026-11-06

## 改动

### 灵动岛更紧凑，加号归位

- 收起态 `140×30 → 116×24`，悬停态 `340×58 → 288×46`，面板 `560×360 → 480×312`；
- 圆环、字号、行高、输入框与底部提示同步缩小，面板留白更少；
- 面板头部把「打开轻单 / 快速添加 / 关闭」收进同一个右侧操作组，去掉 `margin-left:auto`
  造成的多个大间隙；加号改为强调色按钮，位于「打开轻单」和「关闭」之间；
- 按钮组内部留白不再触发面板收起或窗口拖动；
- 胶囊尺寸仍由 `src/shared/island.ts` 统一提供，渲染层与主进程命中判定不会漂移。

### 日历日视图

- 日/周视图改为预取当前月份（含首尾整周）的数据，前后切一天时不再重新查询；
  切换日期直接替换列表，不再先闪一下空状态；
- 只有跨月才需要重新取数，此时用固定高度的骨架行占位，不再闪现「这一天还没有任务」；
- 点日期、点月历任务、滚动月历时都同步写入 `calendarDate`，紧接着点「添加任务」或按 `Ctrl+N`
  都不会读到上一次的日期；新建任务会落到当前切换到的日期。

### 已完成：每日日报

- 已完成视图每个日期分组末尾新增「日报 N 项」，默认折叠，点击展开/收起；
- 展开后按以下纯文本格式展示，并提供「复制」按钮：

  ```text
  2026/11/06：
  1. 写完周报
  2. 跑步 5 公里
  3. 整理明天的待办
  ```

- 普通列表与超过 150 条的虚拟滚动列表都支持日报；超长日报在卡片内滚动，不会把列表撑得过长；
- 日报生成逻辑抽成纯函数 `buildDayReport`，新增 `scripts/test-day-report.ts` 回归格式。
