# LightTodo 0.2.0 修复与验证

日期：2026-11-03。

## 日历

- 月、周、日视图；上一页/下一页、回到今天、日期选择器跳转。
- 单击日期选中并显示当天全部任务；双击空白日期或加号新建，自动带入日期。
- 当天列表支持完成/撤销、打开详情、显示已完成，月格显示任务预览与总数量。
- 拖动任务到日期可修改计划日。方向键移动选中日期，Enter进入日视图。
- 日历默认占用完整工作区，仅选中任务时打开右侧详情。

## 启动和打包

- 已复现当前Windows环境下Electron默认启动在进入主进程前退出，退出码0x80000003；加--no-sandbox后可运行。仅关闭GPU不能解决。
- 原生.NET启动器先正常启动，仅在此退出码且15秒内退出时自动兼容重试；不要求用户修改启动参数。
- 清除继承的Electron/Node环境变量，并关闭打包运行时RunAsNode和NodeOptions fuse。
- 应用启动、页面加载和进程异常记录日志；启动失败提供错误信息。
- 单文件版使用嵌入ZIP并释放到exe同目录，避开当前环境下NSIS临时目录解压失败（退出码2）。目录按构建哈希区分，重复启动复用完整文件，数据保存在LightTodoData。
- 开机启动、URL协议、Jump List及备份恢复重启指向启动器。
- 本轮未修改或迁移日常数据目录；使用独立QA数据。
