# 0.6.2 启动修复 + 岛交互

日期：2026-11-05

## 0. 双击 exe 打不开：根因与修复

现场日志（`LightTodoData/launcher.log`）：

```
2026-11-05T16:20:58 exit=-2147483645   ← 0x80000003
2026-11-05T16:20:58 retry with --no-sandbox --disable-gpu
```

`0x80000003` 是 Chromium 在受限/远程会话里初始化失败（mojo 通道被拒）。旧启动器只把退出码记进日志就结束，用户看到的就是"双击没反应"。

修复：启动器检测到该退出码时**自动带 `--no-sandbox --disable-gpu` 重试一次**，并把两次结果都写进日志。实测：不带任何参数双击 `LightTodo-0.6.2-x64.exe`，第一次失败后自动重试成功，主窗 + 任务岛都起来了。

## 1. 关闭行为（确认）

- 主窗口右上角 `X` → `app.quit()`，**完全退出**，任务岛、托盘图标一起销毁；
- 任务岛右键 → 退出轻单，同样完全退出；
- 最小化按钮（`—`）才会留在任务栏，不会进托盘。

实测：向主窗口发 `WM_CLOSE`，5 秒后所有 `LightTodo*` 进程退出。

## 2. 任务岛只服务“今天”

- 列表只取 `view: 'today'`，已完成按 `completed_at` 当天补回；
- 岛内快捷添加没写日期时**默认落到今天**；
- 勾选只改当天任务状态。

## 3. Ctrl+N 在岛内新增

- 面板打开时窗口临时可聚焦（收起后恢复“不抢焦点”）；
- `Ctrl+N` 直接展开输入框，回车入库；`Esc` 取消。
- 实测：面板内按 Ctrl+N，`.quick-add input` 出现。

## 4. 顶部拖动

- 默认顶部居中；按住胶囊头部左右拖动，纵向永远贴工作区顶部；
- 位置写入 `island_x`，重启恢复；超出屏幕自动夹回。
- 实测：拖动 100px，窗口 x 640 → 517，y 保持 0。
