## 3. 全链路 E2E（8 条旅程）

> 每条旅程由多个 session 组成，session 之间应用完全退出再启动，数据目录不变。

### 旅程 1：收集 → 整理 → 执行 → 完成（跨重启）
收件箱快速添加 3 条 → 打开「季度报告」→ 改到「工作」清单 → 设高优先级 → 排今天 → 加子任务 → **重启** → 今天视图找到 → 完成子任务 → 完成父任务 → 已完成视图可见 → 收件箱计数正确。
结果：✅（21.8s）

### 旅程 2：重复任务连续两轮（跨重启）
添加「每天 9点 站会」→ 完成 → 生成下一次 → **重启** → 再完成 → 生成第三条；断言三条日期逐日递增、RRULE 保留、完成 2 条。
结果：✅（15.1s）

### 旅程 3：清单生命周期
新建「临时项目」→ 在其中添加任务 → 删除清单 → 任务回落到收件箱、任务不丢。
结果：✅（10.2s）

### 旅程 4：搜索 → 打开 → 移动清单
在「工作」添加「季度复盘报告」→ Ctrl+K 搜索 → 打开 → 改到「生活」→ 断言归属变更且任务仍在。
结果：✅（10.0s）

### 旅程 5：跨月日历
添加「12月15日 年度复盘」→ 日历 → 下个月 → 找到任务 → 点开详情。
结果：✅（9.1s）

### 旅程 6：回收站完整循环
删除 → 回收站 → 恢复 → 再删除 → 彻底删除 → 数据库无记录。
结果：✅（13.3s）

### 旅程 7：边界输入
空标题不新增；`<script>` 标题按纯文本保存且不执行；300 字标题可保存；搜索 `%` 不匹配全部（LIKE 通配符转义）。
结果：✅（9.9s）

### 旅程 8：全字段持久化（跨重启）
标题/备注/Markdown、清单、计划日、截止时间、提醒、优先级、标签、子任务 → **重启** → 详情页逐项回显。
结果：✅（19.8s）

## 5. 本轮发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 新任务不在最上面 | `nextSortOrder` 用 MAX+1024，升序排列把新任务排到最后 | 顶层任务改用 MIN-1024（新任务最前），子任务仍追加 |
| 2 | 清单内添加总进收件箱 | QuickAdd 只认 `#清单` | 优先 `#清单`，其次当前清单视图 |
| 3 | 第二次点 exe 不弹窗 | 旧进程占单实例锁且窗口隐藏/销毁 | `showMain` 重建窗口 + 强制置顶；`run.cmd` 清理旧实例 |
| 4 | `run.cmd` 报命令不存在 | 批处理 UTF-8 中文注释被 GBK 解析 | 改纯英文注释 |
| 5 | "工作日"不生成重复 | 正则只认"每工作日" | 兼容裸"工作日" |
| 6 | 搜索 `%` 命中全部 | LIKE 通配符未转义 | 转义 `\ % _` + `ESCAPE` |
| 7 | 备注偶发不保存 | 仅依赖 state，程序化/输入法输入可能不同步 | 保存时以 DOM 实际值为准（ref） |
| 8 | 协议链接带不出文本 | 事件早于渲染进程挂载 | 等 `did-finish-load` 后再发 |
| 9 | 删除后无法找回 | 只有软删除无回收站 UI | 回收站视图 + 恢复/彻底删除 |
| 10 | 清单只能建不能改删 | 无入口 | 侧边栏菜单：重命名/删除（任务回落收件箱） |
| 11 | 提醒下拉测试不生效 | React 受控 select 仅 change 不触发 | 测试改为 input+change（真实操作不受影响） |
| 12 | 收件箱与今天重复 | 两个视图语义重叠、空收件箱无意义 | 移除收件箱入口；今天增加"待安排"分组收纳未分类任务 |
| 13 | 开机自启不生效/勾选不保持 | 读写用了不同 path/args；且只依赖 Electron API | 双写 HKCU Run + Electron 登录项，读取任一为真；`--hidden` 静默启动 |
| 14 | 设置功能太少 | 仅数据/关于 | 新增主题、启动视图、标签管理、提醒开关、清空已完成、备份恢复 |
| 15 | 标签无法管理 | 只有创建/删除 API，无入口 | 设置内标签增删改查 |
| 16 | 无批量删除 | 无多选状态 | 多选模式：全选/完成/删除 |
| 17 | 详情完成状态不联动 | 详情直接调 setStatus，绕过 store 刷新 | 改走 `toggleTask`，列表/日历/计数同步 |
| 18 | 日历任务超过 3 条被隐藏 | `slice(0,2)` + "还有 N 项"不可展开 | 单元格内滚动显示全部任务 |
| 19 | 日历只能看不能加 | 无点击新增入口 | 点击日期格或悬停 + 号，带日期打开快速添加 |

## 7. 手工验收清单（发版前）

1. 双击 `run.cmd` 窗口出现；关闭 → 托盘仍在；再双击 → 恢复。
2. 托盘右键：打开 / 新建任务 / 退出。
3. 提醒设为 1 分钟后 → 系统通知 → 点击跳任务。
4. 开机自启 → 重启系统验证。
5. 导出 JSON / Markdown 文件内容完整。
6. 系统深色模式切换。
7. 任务栏 Jump List（需安装版）。
8. 浏览器 `lighttodo://add?text=测试`。

## 9. 已知限制

- 本机无 GPU：冷启动 3-11s，应用自身开销 <1s；正常机器预期 <1s。
- NSIS 安装包在本机会话生成卸载器时被拦截；便携 zip 已验证。
- 系统通知/托盘/自启属 OS 级，无法在无头脚本可靠断言，列入手工清单。
