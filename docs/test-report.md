## 4. 本测试发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 在清单里添加任务总是进收件箱 | `QuickAdd` 只用 `#清单名`，没用当前视图的 `listId` | 优先 `#清单`，其次当前清单视图 |
| 2 | 点第二次 exe 不弹窗 | 旧进程占单实例锁且窗口已隐藏/销毁 | `showMain` 重建窗口 + 强制置顶；`run.cmd` 先清理旧实例 |
| 3 | `run.cmd` 报"不是内部或外部命令" | 批处理里写了 UTF-8 中文注释，cmd 按 GBK 解析断行 | 改为纯英文注释 |
| 4 | 输入"工作日"不生成重复规则 | 正则只匹配"每工作日" | 兼容裸"工作日" |
| 5 | 提醒下拉设置不生效（测试暴露） | React 受控 select 只派发 change 不触发 | 测试改为 input+change；真实用户操作不受影响 |
| 6 | 协议链接带不出文本 | 事件在渲染进程挂载前发送，丢失 | 等 `did-finish-load` 后再发 |
| 7 | 删除后无法找回 | 只有软删除，没有回收站 UI | 新增回收站视图 + 恢复/彻底删除 |
| 8 | 清单只能建不能改/删 | 无入口 | 侧边栏"更多"菜单：重命名/删除（任务回落收件箱） |

## 6. 手工验收清单（发版前跑一遍）

1. 双击 `run.cmd`：窗口出现；关闭窗口 → 托盘仍在；再双击 → 窗口恢复。
2. 托盘右键：打开 / 新建任务 / 退出 均可用。
3. 设置提醒为 1 分钟后 → 到点弹 Windows 通知 → 点击通知跳到该任务。
4. 设置 → 开机自启 → 重启系统后进程存在。
5. 设置 → 导出 JSON / Markdown → 文件内容完整。
6. 系统切换深色模式 → 应用跟随。
7. 任务栏右键图标 → Jump List "新建任务"（需安装版）。
8. 浏览器打开 `lighttodo://add?text=测试` → 应用弹快速添加并带文本。

## 7. 如何复跑

```bash
pnpm test:unit     # NLP / 导入 / 数据库 / 重复
pnpm test:e2e      # 18 个真实窗口端到端
pnpm test          # 全部
```

E2E 说明：
- 每个场景独立数据目录 `.e2e/<name>/`，跑完可直接查 `lighttodo.db`。
- `E2E_PACKAGED=1 node scripts/e2e.mjs first-run` 可对打包版跑冒烟。
- 本机 Electron 需要 `--no-sandbox --disable-gpu`（脚本已内置）。

---

## 8. 已知限制

- 本机无 GPU，冷启动 ~3s（应用自身 <1s）；正常机器预期 <1s。
- NSIS 安装包在本机会话生成卸载器时被拦截；`pnpm dist:setup` 在正常桌面可出包。便携 zip 已验证。
- 通知、托盘、开机自启等 OS 级行为无法在无头脚本里可靠断言，列入手工清单。
