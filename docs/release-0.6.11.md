# 0.6.11 — 第一梯队：每日闭环与截图任务

本版把调研里「最值得抄」的 8 个能力落到了轻单，重点是让每天三个动作更顺：抓进来、排今天、收个尾。

## 1. 过期任务 Replan

- 每天第一次打开（可在设置 → 节奏关闭）自动弹出「清理逾期」面板。
- 逐条决定：完成 / 今天 / 明天 / 选日期 / 移到也许；支持 `J/K` 选择、`D` 完成、`T` 今天、`M` 明天、`S` 也许。
- 「全部顺延到今天」只处理本次列出的任务；不会在后台自动改期。
- 每次处理写入 `replan_log`，为后续周复盘统计「顺延次数」留数据。

## 2. 估时、今日容量与计时

- 任务详情新增「估时」（15 分钟 ~ 4 小时），任务行显示估时 chip。
- 「今天」标题旁显示容量胶囊：已排 / 可用（默认 9:00–18:00，可在设置 → 节奏修改）。
- 超过 80% 变黄、超过 100% 变红；悬停/聚焦查看已排、可用、实际，并可把低优先级任务一键推到明天。
- 任务详情支持「开始计时 / 停止计时」，实际用时累计到 `tasks.actual_min`，明细写入 `time_entries`。

## 3. 关机仪式

- 侧栏「收工」或托盘菜单打开；设置 → 节奏可配置收工提醒时间（默认 17:30）。
- 一屏完成：今天完成了什么 / 没做完的逐条「明天 / 本周 / 也许」/ 1–5 分评分 + 一句备注。
- 收尾记录写入 `day_reviews`，同一天再次打开可更新。

## 4. 持续催办与紧急提醒

- 任务提醒新增「持续提醒」：每 15/30/60/240 分钟重发，最长 8 小时；完成或稍后才停止。
- 新增「紧急」标记：Windows Toast 使用 urgent 场景，并让主窗口闪烁，直到处理。
- 首次提醒后由 `next_escalate_at` 驱动后续催办；完成后自动清空。

## 5. 清单分区（Heading）

- 清单视图支持「新建分区」，分区可折叠、重命名、删除。
- 任务可拖到分区标题上归组；拖拽不会改变任务本身的状态。
- 删除分区只把任务放回「未分区」，不会删除任务。

## 6. 智能过滤器

- 侧栏新增「过滤器」：保存命名视图，支持 AND / OR 条件。
- 条件覆盖：计划日、截止日、优先级、清单、标签、完成状态、也许、标题/备注、是否逾期、是否无日期。
- 支持「用一句话描述」生成条件（本周 / 今天 / 高优先级 / #清单 / @标签 / 包含「文字」）。
- 编辑器实时显示命中条数，保存后可在侧栏直接切换。

## 7. 命令栏操作符与单键改属性

- 快速添加支持：`=30m` 估时、`>明天` 计划日、`<周五` 截止日、`*标签`（`@标签` 仍可用）。
- 时间段 `10:00-11:30` 会自动拆成开始时间 + 90 分钟估时。
- 选中任务后：`Alt+T` 今天、`Alt+M` 明天、`Alt+S` 也许、`Alt+P` 循环优先级、`Alt+1..4` 直接设优先级。

## 8. 截图任务卡（截图 → OCR → 任务详情）

- 默认快捷键 `Ctrl + Alt + O`（可在设置 → 节奏里录制修改；注册失败会提示被占用并回退）。
- 触发后框选屏幕区域；截图后打开任务卡：左侧是截图，右侧是识别出的任务内容。
- 左侧支持「复制图片」「复制文字」，可直接粘贴到微信。
- 右侧预填标题、清单、计划日、时间、估时、优先级、标签，OCR 原文放在备注里，全部可改。
- OCR 失败不会丢截图：任务卡照常打开，可手动填写。
- OCR 使用 Windows 内置 `Windows.Media.Ocr`，图片通过 stdin 传入 PowerShell，不落盘、不联网。
