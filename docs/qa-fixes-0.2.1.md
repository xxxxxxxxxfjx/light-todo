# LightTodo 0.2.1

## 变化

1. 周视图改为周一至周日的24小时时间轴，区分全天和带时间的任务，同一时段重叠任务并排显示。双击时间格会带入时间新增任务，支持跨周导航，记住上次使用的月/周/日视图。
2. 最小窗口调整为720×520。窗口变窄时侧栏折叠为导航抽屉，任务详情使用覆盖式抽屉，工具栏按可用宽度换行。周时间轴在自身区域内横向/纵向滚动，避免撑出窗口。短窗口降低日历信息密度，保留当天任务列表。
3. Windows原生标题栏按钮的背景和图标颜色随浅色/深色同步。跟随系统时监听nativeTheme.updated；手动选择浅色或深色时同步nativeTheme.themeSource、页面配色及设置持久化。标题栏背景统一为浅色#f3f3f5、深色#1c1c20。

## 验证

- TypeScript主进程与页面类型检查通过。
- 原有状态回归通过。
- 新增 e2e-layout-theme：七天时间轴、全天/定时分区、重叠任务、双击时段新增；1440×900、1100×700、860×640、720×520四档窗口测试；侧栏和详情抽屉；模拟nativeTheme深浅色更新并检查原生overlay实际应用颜色与页面一致；重启保留主题及周视图。
- 系统主题测试通过Electron的nativeTheme事件模拟，不修改Windows个人设置。
