## 1. 别人代码里的「灵动」是怎么做出来的

> 结论先说：「灵动」不是某个特效，而是 **状态少 + 过渡短 + 反馈快 + 尺寸连续**。下面参数都来自源码实测（`文件:行号`），不是感觉。

### 1.1 三套实现的状态与尺寸

| 项目 | 收起 | 悬停 | 展开 | 圆角 |
|---|---|---|---|---|
| **eIsland**（Electron + React） | 260×42 | 500×60 | 860×150 / 860×400 | `0 0 22 22` |
| **fly-island**（Tauri + React） | 340×38 | — | 560×306 | 22 / 30 |
| **win-dynamic-island**（Tauri + Motion） | 220×38 | 260×38 | 520×384 | 19 / 30 |
| WinFinger / WinIsland（WPF） | 300×36 / 120×35 | 390 / — | 920×520 / 400×60 | 18–24 / h÷2 |

**共同点**：收起态高度恒在 **36–42px**，圆角 = 高度/2；展开约 **2× 宽、3–4× 高**；**没有一家做十个状态**。

### 1.2 动效参数（可直接抄）

| 项目 | 形变 | 内容层 | 去抖/延迟 |
|---|---|---|---|
| eIsland | `width/height/radius 0.68s cubic-bezier(.22,1,.36,1)` | 主行 `0.46s` delay `.06s`；动作行 `0.42s` delay `.16s` | hover 进 60ms / 出 80ms |
| fly-island | `560ms cubic-bezier(.16,1,.3,1)` | opacity 120ms / transform 280ms；收起延迟 140ms | — |
| win-dynamic-island | spring `stiffness 380 / damping 32 / mass 0.9` | `duration .16s easeOut`，y ±6px | 收起延迟 160ms |
| WinIsland | 二阶弹簧 `360/28/1`，dt ≤ 64ms，0.5px 静止吸附 | — | — |

**eIsland 的性能注释值得抄**：形变外层**不要加 `transform`**，否则 Chromium 会保留放大后的栅格，文字发虚（`shell.css:54`）；要缩放就放在内层元素。

### 1.3 视觉 token（实测）

| 项 | eIsland | fly-island | win-dynamic-island |
|---|---|---|---|
| 底色 | `#000`（浅色 `#f5f5f7`） | `#2F2F37` + 三段渐变 | `rgba(18,18,24,.72)` → `.86` |
| 描边 | 无（浅色 1px 6% 黑） | `inset 0 0 0 1px rgba(255,255,255,.08)` | `1px solid rgba(255,255,255,.1)` + 内高光 `.16` |
| 阴影 | 深色 none（浅色 `0 2px 16px`） | `0 5px 16px rgba(0,0,0,.12)` | `0 12px 40px rgba(0,0,0,.45)` |
| 模糊 | 主壳无 | `blur() saturate(1.18)` | `blur(14px) saturate(150%)` |
| 字号/图标 | 通知标题 14/600、正文 12、meta 11；通知图标 36、关闭钮 24 | — | — |

**关键发现**：eIsland 主壳**没有** `backdrop-filter`，深色实底 + 细描边就够。不必追毛玻璃。

### 1.4 提醒不是弹窗，是「岛自己变一下」

- eIsland：`setNotification` 直接把状态机推到 notification 并扩窗，按形变时长做保护；关闭靠显式按钮，**未找到自动消失计时器**（unknown）；「稍后」用 `setTimeout(minutes*60*1000)` 重新投递。
- fly-island：QQ 预览每条 5s、突发总截止 10s、微信 5s；空闲 30s 无输入自动收起（默认关闭）。
- 共同做法：**动作按钮直接放在岛里**（完成 / 稍后 / 打开），不做二次弹窗。

### 1.5 窗口不动，只有内容在动

WinIsland 用 800×200 固定舞台、WinFinger 用 980×620 固定舞台（源码注释原话：*"The window is a fixed transparent stage; only IslandBorder animates."*）、win-dynamic-island 用 760×900 固定窗口 + 区域裁剪。

原因：透明窗口 resize 会触发 DWM 重排，掉帧、闪白；Electron 官方也明确「透明窗口不可 resize」。所以「固定窗口 + 内层胶囊动画」是硬约束，不是风格选择。

### 1.6 十条「灵动」规则（写成我们的规范）

1. 收起态高度 36–40px，圆角恒等于高度/2。
2. 展开宽度 ≈ 2×，高度按内容自适应（ResizeObserver），别写死。
3. 形变只动 `width/height/border-radius`，**外层不加 transform**。
4. 主曲线 `cubic-bezier(.22,1,.36,1)`；慢档 560–680ms，快档 280–320ms，不要 ease-in-out。
5. 弹簧等价：`stiffness 380 / damping 32 / mass 0.9`。
6. hover 双向去抖：进 60ms、出 80ms；展开延迟 160ms 防误触。
7. 内容分层入场：主信息 60ms 先到，操作行晚 100ms。
8. 形变末尾叠一次 ≤2.5% 挤压脉冲（`scale .975 → 1`），这是「Q 弹」的来源。
9. 提醒态只加高 20–26px，不做全屏动画。
10. 深色实底 + 1px 8% 白描边 + 大投影，胜过任何毛玻璃。

## 2. 产品定位与「一行」布局

### 2.1 三个动作

| 动作 | 场景 | 交互 |
|---|---|---|
| **看** | 工作时瞥一眼就知道还剩几件 | Rest 态常驻，环 + 数字 |
| **勾** | 刚做完一件事，不想切窗口 | Peek 态直接点 ✓ |
| **加** | 脑子里冒出一件事 | 点岛 → 输入 → NLP 解析 → 回车进收件箱 |

### 2.2 与桌宠的分工

```
┌──────────────────────────────────────────────┐
│              ● 3/7   ·  18:00 写周报          │  ← 任务岛（顶部居中，常驻）
└──────────────────────────────────────────────┘

                                                    🐱   ← 桌宠（右下角，只卖萌）
```

用户说的「在一行」，落成两个可选布局（设置项 `pet.dock`）：

- `corner`（默认）：宠物在右下角，岛在顶部居中，互不干扰；
- `island-line`：宠物吸附在岛的左外侧，同一水平线，像「趴在岛边」。

> 若你说的「一行」是别的意思（比如设置里两个开关并排），告诉我，我改布局即可。

### 2.3 显示条件（避免变成骚扰）

- 今天没有未完成任务 → **不显示**；
- 全屏应用 / 专注模式 → 自动隐藏（P2，先给手动开关）；
- 连续 3 天没点过岛 → 提示一次「要不要关掉任务岛？」；
- 任何时候右键 → 「今天不显示」。

## 3. 状态机（4 态）

| 状态 | 尺寸 | 内容 | 进入条件 | 退出 |
|---|---|---|---|---|
| `hidden` | — | — | 无今日任务 / 手动关闭 / 全屏 | 有任务时淡入 |
| `rest` | 180×36 | 进度环 + `3/7` + 逾期红点 | 默认 | hover 300ms → peek；click → panel |
| `peek` | 360×64 | 环 + 「接下来：写周报 · 18:00」+ ✓ 按钮 | 指针进入 300ms | 离开 600ms → rest；click → panel |
| `panel` | 560×360 | 今日 + 逾期列表，底部「打开轻单」 | click / 提醒 | Esc / 点外部 / 5s 无操作（可配） |
| `toast` | 380×72 | 提醒标题 + 时间 + 「完成 / 稍后」 | 到期前 10 分钟 | 5s 自动 → rest；点按 → 执行 |

**打断规则**（很重要）：

1. `panel` 打开时，`toast` 不抢，等 panel 收起；
2. 拖拽/输入中，任何自动收起都暂停；
3. 同一任务的提醒，10 分钟内只弹一次；
4. 连续完成 3 件 → 弹一次「今天已完成 3 件」的小庆祝（1.6s）。

## 4. 动效规格（直接可写进 CSS/TS）

### 4.1 物理参数

```ts
export const ISLAND_SPRING = { stiffness: 380, damping: 32, mass: 0.9 } // 取自 win-dynamic-island 实测
// 等价近似（CSS 用）：
// width:  680ms cubic-bezier(.22, 1, .36, 1)  // eIsland 实测；快档 280ms
// height: 260ms cubic-bezier(.22, 1.2, .36, 1)
// 收起：  180ms cubic-bezier(.4, 0, 1, 1)
```

| 元素 | 时长 | 曲线 | 备注 |
|---|---|---|---|
| 宽度 | 280ms | 轻回弹 | 先启动 |
| 高度 | 260ms | 轻回弹 | 延迟 40ms |
| 圆角 | 同步 | linear | `= height/2` |
| 内容淡入 | 120ms | ease-out | 延迟 100ms |
| 内容淡出 | 80ms | ease-in | 先于尺寸收起 |
| 数字滚动 | 180ms | cubic-bezier(.2,.9,.3,1) | 上下位移 8px + 0.94 缩放 |
| 勾选 | 220ms | 回弹 | 0.9 → 1.02 → 1 |
| 提醒滑入 | 240ms | 弹簧 | 从 -12px 落下 |

**原则**：同一时刻最多两个属性在动；尺寸先动、内容后到；收起反过来。

### 4.2 微交互

- **指针跟随**：panel 展开时按指针 x 给胶囊 `rotate(±1.2deg)`（和桌宠同一手感）；
- **按压**：`active` 时 `scale(.985)`，80ms；
- **完成反馈**：✓ 图标从按钮飞出到进度环，环 arc 前进 240ms，数字翻页；
- **逾期**：Rest 左侧 4px 红点，每 6s 呼吸一次（不是闪烁）；
- **空状态**：全部完成时胶囊变成一颗「✓ 今天清空」，2s 后自动隐藏。

### 4.3 降级

`prefers-reduced-motion: reduce` → 全部改为 120ms 淡入淡出，无位移。

## 6. 提醒设计（留存的关键）

| 时机 | 表现 | 动作 |
|---|---|---|
| 到期前 10 分钟 | `toast` 落下：「写周报 · 18:00」 | ✓ 完成 / 稍后 10 分钟 |
| 到期 | `toast` 变红边 + 「已到期」 | 同上 |
| 逾期未处理 | rest 左侧红点 + `3/7·1` | hover 显示「1 件已逾期」 |
| 完成后 | 飞出 ✓ + 环前进 | 无 |
| 今日清空 | 「今天清空啦」+ 轻微缩放 | 2s 后隐藏 |

**规则**：不弹系统通知（避免和现有 Toast 重复）；主窗在前台时不弹岛；免打扰时段（22:00–08:00）只更新角标不展开。

## 7. 与轻单的联动（数据流）

```
SQLite (main) ──tasks:changed──▶ 主窗 renderer
      │                └──────▶ 岛 renderer（island:state）
      │
      ├─ 提醒调度（现有 reminder 定时器）──▶ island:toast
      │
岛 renderer ──island:complete(id)──▶ main ──setTaskStatus──▶ 广播 tasks:changed
           ──island:snooze(id,10m)──▶ main ──更新 reminder
           ──island:quickAdd(text)──▶ main ──nlp.parse──▶ 入库
           ──island:openMain(id?)──▶ main ──showMain()
```

- 复用 `notifyTaskWindows()`：把岛窗口加入广播列表（现在只广播 pet + 主窗）；
- 复用 `pet:complete` 的权限校验模式（`assertIsland`）；
- 设置项：`desktopMode: 'off' | 'pet' | 'island' | 'both'`（默认 off），`island_position`、`island_reminders`。

## 9. 技术实现要点（Electron）

1. **窗口**：`transparent: true, frame: false, resizable: false, skipTaskbar: true, alwaysOnTop: true, focusable: false, hasShadow: false, thickFrame: false`；`setAlwaysOnTop(true, 'screen-saver')`。
2. **绝对不要 `setOpacity()`**：透明窗口调用它会把 per-pixel alpha 切成 `LWA_ALPHA`，整窗什么都画不出来（本次桌宠「打开了不展示」就是它）。不透明度用 CSS `opacity`。
3. **固定窗口 640×420**，内层胶囊 CSS 动画；窗口只在显示器变化时 `setBounds`。
4. **点击穿透**：默认 `setIgnoreMouseEvents(true, { forward: true })`；渲染层 `pointermove` + `elementFromPoint` 命中 `.capsule` 时 IPC 关闭穿透，离开恢复（`pet.ts` 已验证）。
5. **键盘输入**（快速添加）：临时 `setFocusable(true)` + `focus()`，收起时还原。
6. **定位**：`display.workArea` 顶部居中；任务栏在顶部时自动让开；多屏跟光标所在屏。
7. **提醒调度**：复用 main 里已有的每分钟检查，新增「提前 10 分钟」偏移。

## 10. 验收清单

1. 1080p/4K、125%/150% 下水平居中，不被任务栏遮挡。
2. 任务栏在上/左/右时，仍贴工作区顶部。
3. 指针划过：300ms 展开 peek，离开 600ms 收回，连续 20 次无抖动。
4. 勾选后：主窗列表同步，环与数字 240ms 内更新。
5. 提醒：到点前 10 分钟弹出 toast，5s 自动收回，点「完成」任务状态正确。
6. 空闲 10 分钟 CPU < 1%，内存增量 < 80MB。
7. 关闭岛：无残留窗口/定时器；与桌宠同时开时互不抢焦点。
8. DevTools 打开时仍可调试（用不透明调试皮肤）。
