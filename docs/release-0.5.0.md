# 0.5.0 · 周复盘与农历

日期：2026-11-05

本版本继续 90 天路线第 4 阶段：新增周复盘视图、农历/节日/调休标注；任务栏角标与桌宠迷你清单沿用 0.4.x 的实现。

## 1. 周复盘

- 侧栏「日历」下新增「周复盘」入口。
- 顶部显示最近 7 天日期范围，可一键「回到今天」「打开收件箱」。
- 四张指标卡：最近 7 天完成、最近 7 天新增、当前逾期、当前待办。
- 7 天双色柱状图（完成/新增），纯 CSS 渲染，无图表库。
- 清单分布：每个未归档清单的最近 7 天完成数与当前待办数；空清单/未知清单归入「未分类」。
- 数据全部来自本地 SQLite；监听任务变更自动刷新。
- 口径：`completed_at` / `created_at` 按本地日期分组；已删除任务不计；`active` 为所有未完成任务（含子任务与也许）。

## 2. 农历、节日与调休

- 月历日期下方显示农历：初一显示月名，其余显示初X/廿X；闰月标记保留。
- 节日优先显示：春节、元宵、龙抬头、端午、七夕、中元、中秋、重阳、腊八、小年；元旦、劳动节、国庆节、清明。
- 2024–2026 法定节假日与调休补班表内置：放假日显示「休」，补班日显示「班」。
- 使用 Chromium/Node 内置 ICU 中国农历（`Intl.DateTimeFormat('zh-CN-u-ca-chinese')`），不联网、不引入额外依赖。
- 2027 年安排未发布，暂不内置；周末自动显示「休」。
