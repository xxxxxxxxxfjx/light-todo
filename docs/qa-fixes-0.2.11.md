# 0.2.11 · 悬停桌宠与日历加载优化

- 默认仅显示 56px 动画宠物，位于主屏工作区右下角；拖动可调整并记忆位置。
- 鼠标移入才显示 190px 任务气泡，移开收起；仅手动滚轮滚动，旧的自动滚动设置已失效。
- 宠物收起时不查询完整任务，任务气泡及日历当天列表均使用可见区域渲染。
- 日历按当前月／周／日范围查询，按计划日优先、无计划日时使用本地截止日期的规则过滤；切换历史日期仍可完整读取。
- 重复点击日历导航不清空重载；任务详情先显示本地已有内容，后台补齐子任务等详情，并保持迟到响应保护。

验证：两套 TypeScript 检查、生产构建及现有全部逻辑回归通过。新增 `test-calendar-range.ts` 验证日期边界、计划日优先、已完成保留、删除过滤及历史任务不截断。8009 条模拟记录的单次对比：全量查询约 71ms，范围查询 7 条约 3.7ms；该数字是本机查询耗时，不代表完整 UI 耗时。

官方 Playwright MCP：默认宠物尺寸 56×56；移入后任务气泡为 190×136；滚轮由第 80 条附近滚动至第 68 条附近；移出后收起。SQLite 验证拖动后的位置记录为 208×220 的窗口坐标。日历 83 条当天任务仅渲染可见行；快照与截图在 `.shots/playwright/`。

日历导航和任务点击均完成真实窗口验证，点击“滚轮验证 01”后详情中的标题正确；截图为 `calendar-detail-0211.png`。初期测试主窗口在后台时出现 Playwright 稳定性等待超时，切换到正确窗口后验证通过；不将 MCP 调用耗时作为应用耗时。

交付文件为 `release/0.2.11/LightTodo-0.2.11-x64.exe` 和便携 ZIP，归档内全部 10 个构建文件与本次构建逐字节一致，SHA-256 见同目录 `checksums.json`。
