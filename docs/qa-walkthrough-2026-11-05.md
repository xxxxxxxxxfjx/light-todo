## 已修复

### 数据与启动

1. **删空清单/任务后重启会重新生成演示数据，甚至因标签唯一键启动失败**
   - `seedIfEmpty` 改为同时检查 lists/tasks，并用 `settings.seeded` 标记；seed 整体放入事务，标签改 `INSERT OR IGNORE`。
2. **重复任务的后继实例被删除后，完成原任务不再生成下一次**
   - `spawnNextOccurrence` 校验后继是否仍存在/未删除；删除、彻底删除、清空已完成时清理 `next_occurrence_id`。
3. **无日期的重复任务完成时静默丢链**
   - 以当天 9 点为基准生成下一次实例。
4. **深层子任务（孙任务）完成/删除/恢复不完整**
   - 改为递归 CTE；新增 `deleted_batch`，恢复时只恢复与根任务同批次删除的子树，避免把先前单独删除的子任务复活。
5. **回收站 30 天清理从未执行，且 ISO 时间比较有边界错误**
   - 启动时执行 `purgeTrash`，改用 ISO 截止时间比较。
6. **恢复备份复制失败后数据库被关闭，应用进入不可用状态**
   - 先复制到 staging 文件；失败时重新 `initDb`；恢复前自动备份当前库。
7. **单实例第二次启动忽略 `--quick-add` / `--hidden`**
   - `second-instance` 现在识别这两个参数。
8. **导入不校验日期/RRULE，非法值会让列表/日历崩溃或任务永远无法完成**
   - `createTask/updateTask` 统一校验日期、提醒时间和 RRULE；导入失败事务回滚并返回可读错误。
9. **同名清单导入被合并**
   - JSON 导入优先按清单 id 建映射，同名清单保留为两个。
10. **设置截止时间后仍被当作全天任务**
    - 更新时间时同步 `due_all_day=0`。
11. **Markdown 导出丢失备注和全部子任务**
    - Markdown 渲染抽到 `src/main/markdown.ts`，按 parentId 递归导出任意层级子任务及备注。
12. **标签计数包含子任务，但标签视图只列顶层任务**
    - 计数口径加 `parent_id IS NULL`。

### 界面与交互

13. **筛选无结果时显示“今天已经清空”并引导新建任务**
    - 改为“没有符合筛选条件的任务”，提供“清除筛选”；错误状态不再叠加空状态。
14. **日期分组不按日期排序**
    - “最近 7 天”按日期升序排列。
15. **已完成/回收站仍显示添加入口，新增后不可见**
    - 隐藏这两个视图的添加入口与空状态新建按钮。
16. **双击任务行会误完成；双击勾选按钮会触发多次 toggle**
    - 移除任务行双击完成；勾选按钮阻止 dblclick 冒泡。
17. **详情标题清空后不回滚**
    - 空标题失焦时恢复原值并提示。
18. **子任务草稿在切换任务后残留**
    - 切换任务时清空草稿；异步完成后不再抢回用户已切换的任务。
19. **无日期任务可以设置提醒但永远不会提醒**
    - 无计划日/截止时间时禁用提醒选择并提示。
20. **已完成任务按 Ctrl+Shift+T/M 提示成功但无效果**
    - 已完成任务改为提示先恢复。
21. **全局 Space/Delete 在详情下拉框、按钮获得焦点时误完成/删除任务**
    - 排除输入控件与按钮；仅任务行/空白区域响应；同时兼容合成事件 target=window。
22. **设置打开时 Ctrl+N 会在遮罩后面打开快速添加**
    - 快速添加入口会关闭设置；设置打开时屏蔽快捷键；设置支持 Esc 关闭与初始焦点。
23. **搜索旧结果未清空，输入新词后回车会打开上一次的任务**
    - 查询变化立即清空结果、显示“搜索中…”，加载中禁用回车；结果超过 60 条给出提示；键盘高亮自动滚动到可见区。
24. **日历点选日期被文字里的日期/时间覆盖**
    - `parseQuickAdd` 增加 `hasExplicitDate`；日历预填日期作为基准，只有显式日期（明天/3月5日等）覆盖；时间只重挂到基准日。
    - 周视图双击空白时间格已按所在列日期落库（不再落到今天/明天）。
25. **月视图点击相邻月灰色日期后标题与议程不同步**
    - 跨月选择会滚动到对应月份；手动滚动月历后议程同步到可见月份。
26. **侧栏清单“更多”菜单无外部点击/Esc 关闭**
    - 增加外部点击与 Esc 关闭，并在切换视图时收起。
27. **文件夹只能新建，不能放清单/改名/删除**
    - 新增文件夹重命名/删除、清单移动到文件夹；删除文件夹时清单回到根目录。
28. **桌宠关闭时点“回到右下角”会重新开启桌宠**
    - reset 不再改 enabled；关闭状态按钮禁用。
29. **桌宠拖拽结束后透明窗口仍拦截点击**
    - 主进程拖拽结束恢复点击穿透，渲染端随后按指针位置恢复交互。
30. **自然语言边界**
    - “每月31号”不再滚到次月1号；“每两周/每两天/每3个星期”可识别。
31. **主题在恢复备份/清空 localStorage 后被 system 覆盖**
    - `app:info` 返回数据库主题；无本地偏好时以数据库主题为准。
32. **TickTick CSV 的“子任务”列被读取但静默丢弃**
    - 按换行/分号拆分后创建真实子任务，完成状态会连同子树一起处理。
33. **批量完成/删除没有进行中状态、删除无确认、Toast 文案误导**
    - 增加 `batchBusy` 禁用按钮；批量删除先确认；提示改为“已移到回收站”。
