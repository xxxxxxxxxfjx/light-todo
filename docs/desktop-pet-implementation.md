# 桌面伙伴 · 首版实现

基于 `desktop-pet-research.md` 的单窗口方案，内置奶油猫咪／草莓兔兔。0.3.0 起新安装默认关闭；升级前已有的安装若没有显式桌宠设置则沿用旧版默认开启。开启时在主窗口就绪后延迟约 8 秒创建，避免和冷启动争资源；初次启动显示在主屏工作区右下角，独立透明置顶窗口，不占任务栏。0.2.12 起随应用退出；关闭主窗口会真正退出，不再隐藏到托盘继续显示。

0.2.11：默认仅显示约 56 × 56 的动画宠物。鼠标移入展开 190px 宽、最多四行可见的任务气泡，移开约 220ms 后收起。背景透明且鼠标穿透；底层 208 × 220 窗口只为气泡预留空间，默认右下角，拖动宠物可移动并保存位置。

## 使用

- 设置 → 桌面伙伴：启停、换肤、85%／100%／115% 大小、不透明度、回到右下角。
- 显示今天及逾期的未完成父任务；不纳入未安排日期的收件箱任务。沿用主窗口今日视图的排序。
- 列表仅使用滚轮浏览，自动滚动代码及设置已移除，旧版 `autoScroll` 值不再生效。长列表仅渲染可见任务。
- 点圆圈完成任务，复用数据库完成逻辑（含子任务和重复任务），实时同步主窗口；点击标题打开详情。
- 拖动宠物调整位置，位置随设置持久化；右键或托盘可隐藏／重新开启。宠物收起时不查询完整任务，展开时刷新。
- 透明空白区鼠标穿透；显示时使用 `showInactive()`，不抢键盘焦点。
- 生命周期由应用管理：退出时销毁窗口、取消定时器，延迟的 ready-to-show 和 IPC 不得再次显示桌宠。便携启动器使用 Windows kill-on-close Job Object 管理整棵子进程树；被强制结束时不会留下桌宠或重试启动。

## 实现入口

- `src/main/pet.ts`：窗口生命周期、设置、工作区边界、任务状态推送、原生菜单。
- `src/preload/pet.ts`：隔离的最小桌宠 API。
- `src/renderer/src/pet/`：独立 React 页面、SVG 伙伴、动画、滚动列表。
- `src/shared/pet.ts`：设置及消息类型。
- `SettingsModal.tsx`：设置分类和桌宠即时配置。

大小使用桌宠页面自身的 CSS transform；桌宠使用独立 session，Chromium zoom 固定为 1，避免继承或影响主窗口的缩放。Windows 透明窗口改变大小时重建该窗口。
