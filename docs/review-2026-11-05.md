# 2026-11-05 代码走查与 0.6.3 修复记录

范围：当天 10 次提交（`9ccfbe1..7000937`，121 个文件）及本次工作区修改。按启动/发布、数据库与导入导出、提醒、日历、周复盘、农历、主窗口与灵动岛审阅，并运行全套现有逻辑回归。不是对所有功能的全量人工验收。

## 本次已修复的不合理之处

1. **P1 单文件解压发布依赖目录重命名**：截图报错指向 `.LightTodo-extract-*` 目录，旧版在完整解压后调用 `Directory.Move`，该步骤失败会阻止启动；异常当时也未写入日志。本版移除该重命名步骤，按包哈希隔离目录、独占文件锁串行解压，最后写完成标记；缺失运行时/应用归档或中断时重新解压，完整异常写入日志。具体是杀毒占用还是权限限制，现场没有堆栈，不能断言。旧包在本机正常权限环境的全新目录启动也能通过，说明不是所有启动都会失败。
2. **P1 发布成功不等于成品可启动**：原打包脚本只产出文件和哈希，`verifiedBuildFiles` 并不证明启动成功。现在标准 `pnpm dist` 自动运行类型、逻辑、启动器、旧 E2E，随后启动实际单文件包和实际 ZIP 解压结果。无参数启动确认窗口就绪且进程运行，再执行已有截图/SQLite 回归；全部成功才写校验清单。已发布版本拒绝覆盖。
3. **P1 主窗口 X 与常驻岛行为不一致**：旧代码实际上 `app.quit()`，与托盘隐藏的预期不符。现在有托盘时隐藏主窗口；任务岛 X 明确标为“退出轻单”，执行完整退出；托盘退出也完整退出。退出由原有 `before-quit` 清理岛、快捷键与数据库。
4. **P1 岛内不是完整 CRUD**：之前只有新增、完成和跳到主窗口。现在接通岛内标题编辑、移入回收站、取消完成，主进程检查目标仍在今日集合内；删除可从主窗口回收站恢复。
5. **P2 日期与入口不一致**：之前允许新增明天的任务，添加后立即离开今日列表。现在岛内固定今日计划日，时间表达式保留时分，跨日表达也归今天；不在岛内创建重复链。Ctrl+N 在已聚焦的岛面板内新增今天任务，空列表继续显示岛。主窗口“今天”本身包含逾期未完成项，岛保持相同口径。
6. **P2 完成列表与统计不一致**：之前统计已完成但没把它们放进 tasks，且直接比较 UTC 日期。现在合并本地当天完成任务，可查看和取消完成，分页避免原 1000 条截断。
7. **P2 默认居中实际靠左**：`Number('')` 得到 0，缺省设置被误当成保存坐标。已改用非数值缺省；拖动仍固定工作区顶部、只改变 X，右键提供恢复顶部居中。
8. **P2 动画和输入互相打断**：之前内容立即卸载，表头高度跳变，收起动画与鼠标命中不同步，移出时可能清空正在输入的草稿。现在内容保持挂载并淡出，表头高度过渡，形变时暂缓命中切换，拖动期间不触发悬停逻辑，输入期间保持展开。减少动态效果的系统偏好会关闭过渡。
9. **P2 新增提交不稳**：之前没有提交锁、错误提示和中文输入法保护。现在阻止重复提交，保存失败保留输入并展示错误，输入法候选确认不提交。
10. **P2 外层便携路径丢失**：原单文件运行了内层启动器，协议注册可能指向解压缓存。现在直接启动运行时，传递外层 exe 的完整路径，主进程协议/跳转列表优先使用外层路径。
11. **P2 启动器测试与代码矛盾**：代码会兼容重试，旧测试却断言不重试。已修正并增加真实嵌入 ZIP 的并发、环境清理、中断恢复回归；岛内写操作同步更新任务栏角标。
